<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (client switcher state) → POST /api/chat | Only a `clientId` crosses; the isolation decision is made server-side, not trusted from the browser |
| server → Anthropic / Tropicalia | Server-only secrets used to generate/retrieve; responses streamed back |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Elevation of Privilege / Tampering | route.ts client resolution | mitigate | `tropicalia_project_id` derived ONLY from an RLS-scoped `.eq("id", clientId).single()`; request body never carries a project id; empty result → 403, never a shared/default project |
| T-2-03 | Denial of Service (cost) | conversation history sent to Claude | accept | D-03 keeps a single ongoing history; unbounded growth is a known future concern, cheap to cap later without a schema change |
| T-2-07 | Tampering (client-side race) | chat-panel stale stream | mitigate | `shouldAppendChunk` + `AbortController` drop/cancel a prior client's stream on switch (Pitfall #3) |
| T-2-04 | Information Disclosure | route.ts secrets | mitigate | Anthropic/Tropicalia clients imported only in the server Route Handler, never into the `"use client"` panel |
</threat_model>
