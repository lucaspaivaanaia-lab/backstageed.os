```sql
create table public.clients (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  created_at timestamptz not null default now()
);
alter table public.clients enable row level security;
```

Existing helper to mirror exactly (supabase/migrations/0004_rls_policies.sql, `is_admin()`):
```sql
create or replace function public.is_admin()
returns boolean language plpgsql stable security definer set search_path = ''
as $$
begin
  return exists (
    select 1 from public.profiles
    where id = (select auth.uid()) and role = 'admin' and status = 'approved'
  );
end;
$$;
```

Existing policies THIS plan replaces (0004_rls_policies.sql, lines ~129-140):
```sql
create policy "clients_insert_admin_only" on public.clients for insert to authenticated
  with check ((select public.is_admin()));
create policy "clients_update_admin_only" on public.clients for update to authenticated
  using ((select public.is_admin())) with check ((select public.is_admin()));
```

Existing policy THIS plan does NOT touch (0004_rls_policies.sql, lines ~101-105) -- Pitfall 3 discipline:
```sql
create policy "pm_clients_insert_admin_only" on public.pm_clients for insert to authenticated
  with check ((select public.is_admin()));
```

`pm_assigned_clients()` (already exists, 0004_rls_policies.sql) -- reuse, do not redefine:
```sql
create or replace function public.pm_assigned_clients()
returns setof uuid language plpgsql stable security definer set search_path = ''
as $$ begin return query select client_id from public.pm_clients where pm_id = (select auth.uid()); end; $$;
```
