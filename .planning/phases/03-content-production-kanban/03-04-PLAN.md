<objective>
Let a PM attach Google Drive links to a card without leaving the platform: paste a link, pick its type, see it listed with an icon, click through to Drive in a new tab, remove it when it is wrong (KAN-05, D-07/D-08/D-09).

Purpose: KAN-05. Links, not files — no Google Drive API, no OAuth, no picker, no thumbnails (D-07/D-08, all explicitly out of scope).

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `addAttachment` | `url`, `label`, `linkType`, `cardId` are all attacker-controlled; the stored URL is later rendered as a clickable link for other users |
| browser → `removeAttachment` | `attachmentId` is attacker-controlled |
| stored URL → other users' browsers | An attachment is rendered as an `<a target="_blank">` that a reviewer will click |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
