<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `createPiece` | `parentCardId` and `title` are attacker-controlled; the piece's client scope must never be derived from browser input |
| cards hierarchy → RLS | A piece is scoped by its own denormalized `client_id`, which must always equal its parent's |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-31 | Information Disclosure | Cross-client write primitive — creating a piece whose `client_id` differs from its parent's, producing a row visible to one PM and parented under another client's card | mitigate | `createPieceSchema` has no `clientId` field at all; `client_id` is copied from the parent row re-read through the RLS-scoped client, so a caller cannot influence it. `cards_insert_scoped` independently rejects an insert for an unassigned client |
| T-03-32 | Tampering | Parenting a piece under a `single` card or under another `piece`, producing a deeper hierarchy the board cannot render | mitigate | `createPiece` rejects any parent whose `card_type` is not `package`; `cards_piece_requires_parent` enforces the non-null parent at the database layer |
| T-03-33 | Tampering | A package row acquiring a stage and appearing in a column, or a piece losing its parent | mitigate | The `cards_package_has_no_stage` and `cards_piece_requires_parent` check constraints from 0015 reject both at the database layer; the board groups on `card_type` and never forces a null-stage row into a column (Pitfall 4) |
| T-03-34 | Repudiation | A package-level advance silently moving pieces past their individual gates | accept — by design excluded | There is no package-level advance action and no cascade: `advanceStage` operates on exactly one card id, and D-02 locks that the checklist gate is per piece. Any future cascade would be a regression against CHK-03 |
| T-03-35 | Tampering | A stored rollup column drifting out of sync with its children | mitigate | The rollup is computed at render time by a pure function over the children's stages and is never persisted (03-RESEARCH.md Anti-Patterns) |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed in this plan. If a task turns out to need one, stop and run the Package Legitimacy Gate protocol first. |
</threat_model>
