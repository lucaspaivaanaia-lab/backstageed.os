<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `createPiece` | `parentCardId` and `title` are attacker-controlled; the piece's client scope must never be derived from browser input |
| cards hierarchy → RLS | A piece is scoped by its own denormalized `client_id`, which must always equal its parent's |
| drag state → `moveCard` | A piece is a first-class draggable card; a package must never become one |
