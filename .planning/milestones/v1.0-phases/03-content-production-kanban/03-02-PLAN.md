<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Server Action | `clientId`, `cardId`, and `title` arrive as untrusted arguments; Server Actions are callable without the UI |
| browser → RSC searchParams | `?client=<id>` is attacker-controlled and drives the board query |
| Server Action → Postgres | Card inserts/updates cross into per-client data; RLS is the last line |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Information Disclosure | Cross-client leakage through the self-referencing `cards` hierarchy — a PM reading another client's `piece` via a shared `parent_card_id` | mitigate | `client_id` denormalized onto every row including pieces (03-RESEARCH.md Pattern 1), so every policy is a flat non-recursive check; asserted by pgTAP assertion 3 in Task 1 |
| T-03-07 | Elevation of Privilege | Self-referencing RLS recursion silently disabling the policy at query time | mitigate | No `cards` policy may contain `from public.cards`; enforced by the Task 1 grep gate (`grep -ci 'from public.cards' == 0` after stripping comments) |
| T-03-08 | Tampering | `createCard` called directly with a `clientId` the caller is not assigned to | mitigate | `createCard` re-resolves the client through the RLS-scoped client and aborts on a null result before inserting; `cards_insert_scoped` independently rejects the insert |
| T-03-09 | Tampering | `advanceStage` called with an arbitrary `cardId`, or with a forged target stage | mitigate | The action accepts only `cardId` — the target stage is never a parameter, it is derived server-side from `nextStage(card.stage)` after re-reading the card through RLS |
| T-03-10 | Elevation of Privilege | `cards` table shipped with RLS enabled but no GRANT (the repeated Phases 1/2/5 lesson) | mitigate | `grant select, insert, update on public.cards to authenticated;` ships in 0015 alongside the policies, asserted by the Task 1 grep gate |
| T-03-11 | Tampering | Unbounded card title inflating payloads or breaking the board layout | mitigate | `createCardSchema` bounds `title` with `.trim().min(1).max(200)` (ASVS V5) |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No packages are installed in this plan (03-RESEARCH.md "Package Legitimacy Audit — Not applicable"). If a task turns out to need one, stop and run the Package Legitimacy Gate protocol first. |
</threat_model>
